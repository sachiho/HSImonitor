1. 全体構成

本システムは、LVYUAN HSI3000U（SRNE OEM 互換）インバータの RS485 (Modbus RTU) ポートに ESP32 (Lolin32 OLED) を接続し、以下の 2 つの役割を同時に実現します。

  • Wi-Fi ⇔ RS485 完全透過ブリッジ（TCP Port 8888）：PC の Python 監視サーバーから無線でインバータをリアルタイム監視・設定変更。
  • ESP32 自律バッテリー救済コントローラ（HTTP API Port 8889）：PC が停止・再起動中であっても、ESP32 単独でバッテリー電圧低下を検知し、充電優先順位 [06] を OSO（太陽光のみ）から CSO（商用緊急充電）へ自動切替・回復復帰を実行。
[HSI3000U インバータ]
       │  RS485 (9600bps / Modbus RTU / Slave ID=1)
       ▼
[ESP32 (Lolin32 OLED) + RS485モジュール]
  ├── 自律救済エンジン & NVS(Preferences) ── PC不在時も2秒周期で監視・緊急充電切替
  ├── TCP Port 8888 (完全透過ブリッジ)  ── 通過パケットを受動スニッフィング(衝突ゼロ)
  └── HTTP Port 8889 (/api/rescue)      ── 救済設定の読み書き・状態同期
       │  Wi-Fi (LAN)
       ▼
[PC 監視サーバー (server.py / FastAPI)]
  └── HTTP / WebSocket (Port 8000)
       │
       ▼
[ブラウザ / スマートフォン Web UI]
RS485 バス調停の仕組み： PC サーバーが接続している間、ESP32 は通過する Modbus 応答を受動スニッフィング（盗聴）して電圧や設定値を取得するため、RS485 バス上で通信が衝突しません。PC が切断されると 2 秒周期の自律ポーリングへ自動で切り替わります。

2. ハードウェア作成

必要な部品

  • マイコンボード：ESP32 Lolin32 OLED（0.96インチ SSD1306 I2C OLED 内蔵）
  • RS485 変換モジュール：自動送受信切替タイプ（3.3V 対応、TX/RX と A/B 端子のみの 2 線式が推奨）
  • LAN ケーブル（RJ45）：HSI3000U の RS485 通信ポート接続用
  • 電源：USB 5V 電源（インバータ付近のコンセントまたは DC-DC コンバータ）

ESP32 ⇔ RS485 モジュール結線

ESP32 (Lolin32 OLED)接続先備考
GPIO 25 (Serial2 RX)RS485 モジュール RO / RXDHSI485conv.ino の RS485_RX
GPIO 26 (Serial2 TX)RS485 モジュール DI / TXDHSI485conv.ino の RS485_TX
3.3V / GNDRS485 モジュール VCC / GND3.3V 動作を必ず確認
GPIO 5 / GPIO 4内蔵 OLED SDA / SCL基板内部で配線済み（I2C 0x3C）

HSI3000U (RJ45) ⇔ RS485 結線

インバータ本体の通信ポート（RJ45）から RS485 A(+) / B(-) を取り出し、RS485 モジュールの A・B に接続します。通信応答がない場合は A と B を入れ替えて確認してください。

注意： USB-RS485 アダプタを使って PC とインバータを直接繋ぐ場合は、ESP32 側の RS485 配線（または電源）を外してください。同一 RS485 バス上に PC と ESP32 が別々にマスターとして繋がると通信が衝突します。

3. ESP書き込みとESP単体での動作チェック

Arduino IDE での設定と書き込み

  1. Arduino IDE で HSI485conv.ino を開きます。
  2. ライブラリマネージャから以下をインストールします（HTTP/NVS 関連は ESP32 コア標準付属）：
    • Adafruit GFX Library
    • Adafruit SSD1306
  3. コード先頭付近の Wi-Fi 設定をご自身の環境に合わせて書き換えます： 
    const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
  4. ボード設定で WEMOS LOLIN32（または ESP32 Dev Module）を選択し、USB 接続して書き込みます。

OLED 画面の見方（PC なし単体動作時）

電源投入後、PC サーバーを起動しなくても ESP32 単体でインバータと通信し、以下の 5 行が表示されます。

192.168.1.85 *
25.4V
PC:WAIT
-58dBm
PWR: INVERTER
CHG:OSO RSC:WAIT
23.5->CSO 24.6->OSO
  • 1行目：Wi-Fi 接続中は WiFi Connecting...、接続後は IP アドレス（PC 接続時は [PC] 付記）と通信点滅 *。
  • 2行目：現在のバッテリー電圧（大文字）、PC 接続状態（PC:WAIT / PC:LINK）、Wi-Fi 電波強度。
  • 3行目：PWR: INVERTER（インバータ給電） / PWR: BYPASS (AC)（商用パスルー）等の運転状態。
  • 4行目：充電優先順位（OSO/CSO 等）と救済状態（WAIT / ACTIVE! / OFF）。
  • 5行目：救済開始・終了電圧、または切替判定中のカウントダウン（例：RESCUE ->CSO (4/10s)）。

HTTP API による単体動作チェック

PC やスマホのブラウザ、または curl で以下の URL にアクセスし、JSON が返れば ESP32 単体での動作は正常です。

curl http://<ESP32のIPアドレス>:8889/api/rescue
Wi-Fi に繋がらない環境でも、ESP32 は 5 秒ごとに裏で再接続を試みながら、RS485 監視と自律バッテリー救済を継続します。

4. PCサーバーからのアクセス

初回セットアップ（Windows）

  1. Python 3.10〜3.12 をインストールします。
  2. setup_requirements.bat を実行（または pip install -r requirements.txt）して依存パッケージをインストールします。
  3. 必要に応じて server.py 内の接続先 IP（初期値 socket://192.168.1.85:8888）を ESP32 の OLED に表示された IP に書き換えます。

起動と停止

  • 起動：run.bat（または python -u server.py）を実行します。起動中は黒いコンソールウィンドウを開いたままにします。
  • 停止：stop.bat を実行します。

Wi-Fi 接続と USB-RS485 直結の自動切替

server.py は接続ポートに応じて救済処理の方式を自動で切り替えます：

  • socket://... 接続時：ESP32 自律監視モード（PC は Port 8889 から状態同期のみ実施）。
  • COMx（USB-RS485 直結）時：PC 監視モード（自動的に Python 側のローカル救済制御へフォールバック）。

5. WEBでの操作

サーバー起動後、PC のブラウザで http://localhost:8000 を開きます。同じ Wi-Fi 内のスマートフォンやタブレットからは http://<PCのIPアドレス>:8000 で閲覧・操作できます。

主な画面と操作

機能・パネル操作できること
リアルタイム電力フロー & 推移グラフ 太陽光(PV)・バッテリー・商用(Grid)・AC負荷の電力の流れをアニメーション表示し、過去24時間の推移を確認できます。
夜間バッテリー保護・自動救済充電 自動救済の ON/OFF、救済開始電圧（例: 23.5V）、救済停止電圧（例: 24.6V）を設定して「閾値設定を保存」を押すと、ESP32 側の NVS に即座に書き込まれます。
充電優先順位の手動切替 CSO（太陽光優先）・CUB（商用優先）・SNU（同時充電）・OSO（太陽光のみ）を直接切り替えできます。手動で OSO に戻すと ESP32 側の救済状態も自動で待機に同期します。
バッテリー詳細 / 履歴 / 障害診断 LiFePO4 8S 適応型 SOC 推定、1分間隔・日別集計グラフ、全64種のエラーコード事典、CSV ログダウンロードが利用できます。
